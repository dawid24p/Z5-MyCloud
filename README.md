# Grad — Z5

Projekt z zadania Z5, rok 3, semestr 1.

## Zawartość

- `z5/` — rozpakowane pliki projektu PHP, JavaScript i CSS oraz zasoby.
- `baza-z5.sql` — zrzut bazy danych dołączony do archiwum.
- `archives/z5.zip` — oryginalne archiwum Z5.

Pliki projektu i archiwum zachowano bez zmian. Z6 pominięto.
